# 口述影像：分段与时间策略

本文沉淀「片段切分」和「旁白时间/语速/混音」两块讨论结论，作为后续落地依据。
参照：WCAG 2.1（1.2.5 / 1.2.7）、ITC/Ofcom、DCMP Description Key、Netflix AD Style Guide、国内「光明影院」实践。

---

## 0. 一句话原则

- **两条独立的线，别混**：
  - **内容线**：按「镜头」切分 → 决定「描述哪个画面单元」。
  - **时间线**：按「对白空隙」插入 + 「字数预算」控制长度 → 决定「什么时候播、能说多少字」。
- 数据模型每条脚本是 `startMs + durationMs`，本来就支持变长，下游（时间轴/试听/自动播放）基本零改动。

---

## 1. 片段切分：镜头分段 + 钳制（替换现在的固定 3 秒）

**问题**：现在按固定 3 秒切（`SEGMENT_SECONDS=3`），切点与画面无关，可能把一个镜头切两半 → 描述不连贯。

**方案**：用 FFmpeg 场景检测（自带，无新依赖；解析方式同现有 `parseSilences`），**不要纯按镜头切**，要加钳制：

```
1. 场景检测得到镜头边界（ffmpeg -vf select='gt(scene,T)'）
2. 合并：相邻段 < 最短阈值 → 并入邻段
3. 拆分：单段 > 最长阈值 → 按时间等分
4. 兜底：没检测到任何切点 → 回退固定时间切
```

**在样片《丧尸清道夫》(213.5s) 实测**（验证用，非最终）：

| 方案 | 段数 | 最短/中位/最长(s) |
|---|---|---|
| 固定 3s（现状） | 72 | 3.0 / 3.0 / 3.0 |
| 纯检测 scene>0.3 | 72 | 0.03 / 2.43 / 19.81 ❌畸形 |
| **scene>0.3 + 钳制** | **60** | **1.50 / 3.20 / 6.60 ✅** |

**推荐默认参数**：`scene 阈值 0.3`、`最短 1.5s`、`最长 8s`。
**注意**：阈值随片型变化（AI 短片 / 访谈 / 录屏 不同），必须做成**可配置**并在目标片上实测；AI 视频易过度分割。
**落地点**：改 `extractSegments` + 新增 `detectScenes`（与 `detectSilences` 同级）；多一次解码 pass，约 2s/片，可接受。

---

## 2. 对白空隙检测：检「语音」不是检「声音」

**问题**：现在用 `silencedetect` 检的是整条混音的安静段——背景音乐一响就不算静音，会漏掉「没人说话但有音乐」的可插入位置。而且现在旁白根本没用空隙，是直接在段首播的。

**规范铁律**：**旁白只能落在对白停顿处，绝不盖对白**（优先级高于一切混音技巧）。

**做法（按优先级）**：
1. **有字幕(SRT/VTT)**：字幕区间=对白区间，字幕之间的缝=候选旁白槽（最省事，对应 MVP「应该有」）。
2. **无字幕**：VAD / ASR 语音活动检测，取「无人声」区间。
3. `silencedetect` 仅作最粗兜底。

**量化约定**：空隙 **< ~1.5–2s 不值得插**，放不下就别硬塞，标记为需人工/扩展处理。

---

## 3. 语速：固定，不自适应变速

**结论**：用**固定、自然**语速。**不做逐段自动变速**——忽快忽慢会增加认知负担、前后不一致、听感乱（这点规范明确反对）。

**空隙不够时的正确顺序**（不是提速）：
1. **缩短文本**：砍到只留最影响理解的视觉信息（屏幕文字、关键动作优先）。
2. **挪位**：放到相邻更长的空隙。
3. **扩展口述影像（Extended AD，WCAG 1.2.7）**：仍放不下就**暂停画面**让旁白念完——这是「段落太短」的官方解法，不是飙语速。

**关键设计思路（反过来）**：
> 不是「段落 X 秒 → 把字读快塞进去」，
> 而是「空隙 X 秒，中文约 4–5 字/秒 → 这条描述最多 ~X×4.5 字 → 让模型按此字数上限生成」。

即：**语速固定，用「字数预算」适配时间**。例：2s 空隙 ≈ 8–10 字，prompt 里告诉模型「≤10 字」。

---

## 4. 混音 / Ducking

- **铁律**：绝不在对白上叠加旁白（见 §2）。
- **背景音乐/环境音**：业内标准会在旁白那几秒**轻度下压（约 -6 ~ -12 dB）**，旁白结束抬回，不是全程静音。
- **当前取向**：按需做成开关。可默认不压或只做「仅旁白那几秒、只压原声不动旁白」的轻 ducking；但向用户说明「标准做法是压背景床」。

---

## 5. 落地优先级建议

| 优先级 | 事项 | 收益 | 改动面 |
|---|---|---|---|
| P0 | 空隙检测升级（字幕优先 / VAD） | 直接决定成片是否盖对白 | 中 |
| P0 | 字数预算（空隙时长→字数上限喂模型） | 时长对齐、固定语速 | 小（prompt + 计算） |
| P1 | 镜头分段 + 钳制（替换固定 3s） | 描述连贯、段数更少更省 | 集中在 `extractSegments` |
| P2 | 扩展口述（暂停插入） | 短空隙的正规解法 | 较大（播放/导出流程） |
| P2 | Ducking 开关 | 音乐场景听清旁白 | 导出混音阶段 |

> 提醒：§1 镜头分段（内容线）与 §2/§3 空隙+字数（时间线）是两条线，可分别独立推进、独立验证，不要一次混改。
